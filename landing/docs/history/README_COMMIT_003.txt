FMW WEB — COMMIT 003

Ejecución:
1. Instalar Node.js 20 o superior.
2. Definir FMW_ADMIN_TOKEN.
3. Ejecutar: npm start
4. Abrir: http://localhost:3000
5. Panel: http://localhost:3000/admin.html

Este commit agrega persistencia de leads y eventos mediante backend Node.js sin dependencias externas. Las credenciales de Mailchimp y CompraClick no se exponen en el navegador.
